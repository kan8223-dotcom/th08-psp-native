# r249 / v0.4.0 publication record

Public product: `r249T-audio-me-nolog-20260922`, 5,308,064-byte EBOOT,
PSP Go native renderer, MECC audio-only, diagnostic output OFF, CPU usage
graph OFF, normal DEBUG0. It is rebuilt from r249, not the exact logged PBP
tested on Go. The logged r249 completed the physical Go6B replay before
publication; the exact no-log product has separate PPSSPP validation below.

## Feature and safety boundary

MECC (PSP Media Engine Custom Core, m-c/d, MIT) is statically linked with an
embedded private `th08_audio_kcall.prx`. Audio mixing is the only ME workload.
PCM snapshots, output, mailbox and guarded worker stack use low Main RAM.
No ME local-eDRAM/MIST cache or minimal VME setup is enabled. The native
renderer uses the separate GE4MiB aperture via `ge4wrap_texv1.prx`.

Whole eligible callbacks preserve voice order and saturation. Boot selftest,
unsupported-workload fallback, 8ms timeout/packet quarantine, STOP ACK and
owned firmware callback restoration remain enabled in the no-log build.
An unresponsive worker is not unloaded: a cold reboot may be necessary.

No BOOT/performance/SDL/game trace files are created or rotated. Old files are
left alone. Saves/replays and runtime extraction of the MECC helper still work.
CPU graph is not drawn; ordinary game FPS remains. RAM profiling counters are
retained: this does not claim zero measurement cost.

r247; 180second42generation demo has no retained terminated pthreads;

Exact public product: normal pad input, public Noto font only, music-room

Current native version is verified on Go only. PSP-2000/3000 are unverified;

claim is made: the canonical private target is unavailable in this checkout.

## Rebuild / replace the LGPL pthread library

```sh
JOBS=8 bash tools/build_go_r249_release_20260922.sh
```

All source/config/generation scripts are in the release tag. Default is a clean
build. No original game archive or private build-directory script is required.
PSPDEV, PSPSDK, PSP SDL2/image/ttf, psp-gcc15.2, CMake, Python3 and xxd are used.

The release includes `PTHREADS_SOURCE_4f43d30_20260909_183252.tar.gz`, the
corresponding pthread-embedded upstream source at
`4f43d30a23e8ac6d0334aef64272b4052b5bb7c2`. Build/install a modified library
with `make -C platform/psp` and `make -C platform/psp install`, then rebuild
this application. Modification/debugging for this purpose is not restricted.
SDL2/image/ttf use zlib-type licenses; pthread-embedded is the LGPL component.

MIT/MECC/runtime license texts and Noto OFL accompany the binary package.
This software uses the FreeType Project font engine. This software is based
in part on the work of the Independent JPEG Group.
No original game archives, MS fonts, saves, replays or test/device logs are
distributed. Exact final packages must pass the private-font boundary audit.
